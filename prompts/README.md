# Example prompts

The system and user prompts sent for CARLA scene 241. The system prompt is the same for every configuration.

| File | Prompt |
|---|---|
| `system_full_carla_video.txt`, `user_full_carla_scenario241.txt` | full prompt |
| `system_withheld_carla_video.txt`, `user_withheld_carla_scenario241.txt` | no-parameter prompt |

`simulation/build_pilot.py` builds these and the target-only prompt for any scene.
